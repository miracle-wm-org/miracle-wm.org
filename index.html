Miracle is a tiling Wayland window manager built on top of Mir.

Goals:

  • 🔗 to be compatible with sway IPC
  • 📸 to create a flashy tiling window manager that absolutely anyone can use, similar to hyprland but with less of a focus on expert users
  • 🚩 to be the flagship example of a full-featured window manager built on top of Mir
  • 🫂 to foster a welcoming and friendly community
